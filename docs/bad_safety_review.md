# Проверка правил безопасности БАД — на подтверждение врачу

Это свод всех автоматических предупреждений, которые бот показывает пользователю
на основе его профиля здоровья (хронические заболевания, аллергии, препараты) при
подборе БАД. Каждое правило написано мной (не врачом) и подкреплено ссылкой на
источник — но ни одно из них не заменяет консультацию специалиста. Пожалуйста,
отметьте для каждого пункта: **подтверждаю** / **нужно скорректировать** (и как) /
**убрать**.

Формулировки в колонке «Текст пользователю» — то, что реально увидит человек в
боте (с подстановкой названия БАД).

**Отдельно по вашему замечанию про сустав**: отдельного продукта для суставов
(глюкозамин/хондроитин/МСМ) в каталоге не будет. Вместо этого бот теперь честно
говорит, что при жалобах на суставы нужна добавка не из нашего ассортимента —
без попытки подогнать это под магний/коллаген/D3.

## 0. Общая осторожность (срабатывает на любой БАД)

| Состояние | Текст пользователю |
|---|---|
| Тромбофилия / склонность к тромбозам / варикоз / гиперкоагуляция | «в вашем профиле указано «нарушение свёртываемости крови / тромбофилия» — это существенная особенность здоровья, перед приёмом любых БАД проконсультируйтесь с врачом.» |

Источник: без конкретной научной ссылки — это общая перестраховочная реплика,
не привязанная к конкретному веществу (её задача — не пропустить случай вроде
вашего, где ни один продукт не содержит проблемного компонента напрямую).

## 1. Магний (хелат 1000 мг)

| Триггер | Тип | Текст пользователю | Источник |
|---|---|---|---|
| Заболевания почек | заболевание | «при заболеваниях почек возможно накопление магния — уточните у врача.» | NIH ODS Magnesium Fact Sheet |
| Брадикардия | заболевание | «магний может дополнительно замедлять пульс — при брадикардии принимайте только по согласованию с врачом.» | NIH ODS Magnesium Fact Sheet (раздел о симптомах избытка) |
| Гипотония | заболевание | «магний способен снижать давление — при гипотонии принимайте только по согласованию с врачом.» | NIH ODS Magnesium Fact Sheet |
| Миастения | заболевание | «магний может усиливать мышечную слабость при миастении — обязательно уточните у врача.» | Механизм: блокада входа кальция в нервные окончания → снижение высвобождения ацетилхолина (стандартное противопоказание в клинической фармакологии) |
| Тетрациклины | препарат | «магний снижает всасывание тетрациклинов — разнесите приём минимум на 2–3 часа.» | NIH ODS Magnesium Fact Sheet (Interactions with Medications) |
| Бисфосфонаты | препарат | «магний снижает всасывание бисфосфонатов — разнесите приём по времени, уточните у врача.» | NIH ODS Magnesium Fact Sheet (рекомендован интервал ≥2 ч) |
| Левотироксин | препарат | «магний может снижать всасывание левотироксина — разнесите приём минимум на 4 часа.» | Drugs.com Interaction Checker |

## 3. Синергия/сочетаемость (не предупреждения о риске, а справочные заметки)

| БАД | Заметка пользователю | Источник |
|---|---|---|
| Витамин D3 | «магний — необходимый кофактор для превращения витамина D в активную форму. При его нехватке приём D3 может быть менее эффективным.» | NIH ODS Vitamin D Fact Sheet; PMC6693398 |
| Витамин D3 | «теоретически витамин K2 помогает направлять кальций в кости, а не в сосуды, и его иногда сочетают с D3 — но крупные рандомизированные исследования пока не показали однозначной клинической пользы такой комбинации, поэтому не считайте это обязательным.» | PMC11313760 (механизм) — **но** реальное РКИ AVADEC (PMC11198368, JACC: Advances) не показало значимого эффекта за 2 года, в одной подгруппе кальцификация аорты могла даже усиливаться. Намеренно смягчено — это гипотеза, не доказанная синергия. |
| Коллаген | «витамин C необходим для синтеза собственного коллагена в организме — в нашем продукте он уже включён в состав.» | NCBI StatPearls, Biochemistry of Collagen Synthesis (NBK507709) |

## Как использовать этот документ

Для каждого блока (0–3) отметьте один из вариантов:
- ✅ формулировка и источник корректны, оставляем как есть;
- ✏️ корректно по сути, но формулировку нужно изменить (напишите, как);
- ❌ убрать — правило либо неверно, либо избыточно.

Отдельный открытый вопрос к вам: подходят ли эти источники (NIH ODS, Mayo Clinic,
PubMed, NCCIH, StatPearls, клинические рекомендации РАЭ/ESCEO) как достаточный
уровень доказательности для бота, или для части пунктов нужен более строгий
источник (например, конкретное РКИ или Кокрейновский обзор)?
